# Descarga de datos

Para la descarga de datos se incluye el comando `asent-mex:fetch-data`,
el se encarga de descargar y procesar los datos de Correos de México,
generando archivos CSV y [enums](explicacion_a_detalle/enums.html).

Este comando no cuenta con argumentos u opciones.

```bash
php artisan asent-mex:fetch-data
```
